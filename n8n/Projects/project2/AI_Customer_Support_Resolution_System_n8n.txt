AI CUSTOMER SUPPORT RESOLUTION SYSTEM
n8n Project — Complete Step-by-Step Build Guide

PROJECT NAME
AI Customer Support Resolution System

PROJECT GOAL
Build an AI support-ticket automation system that:
1. Receives a customer support email.
2. Extracts customer and issue information.
3. Classifies the ticket.
4. Assigns priority.
5. Searches a company knowledge base.
6. Generates a suggested resolution.
7. Decides whether human approval is required.
8. Sends a reply when safe.
9. Stores the ticket in Google Sheets.
10. Tracks SLA and escalates unresolved tickets.

IMPORTANT
- Build and test one node at a time.
- Node names can vary slightly by n8n version.
- In your current n8n version: Manual test trigger = “When clicking ‘Execute workflow’”.
- Current Set node name = “Edit Fields (Set)”.
- Check the node UI before assuming a parameter exists.

NODE 2 — AI Agent
============================================================

Node name:
AI Ticket Analyzer

Connect:
Gmail Trigger -> AI Ticket Analyzer

Source for Prompt (User Message):
Define below

Prompt:
Analyze this customer support email.

Email content:
{{ $json.snippet }}

Extract:
1. Customer name
2. Customer email
3. Subject
4. Main issue
5. Category
6. Priority
7. Whether human approval may be required

Allowed categories:
Technical Support
Billing
Account
Training
General

Allowed priorities:
Low
Medium
High
Critical

Rules:
- Do not invent information.
- Technical problems are Technical Support.
- Payment/invoice issues are Billing.
- Login/profile/access issues are Account.
- Course/batch/schedule questions are Training.
- Everything else is General.
- Serious service-blocking problems may be High.
- Security, financial-risk, or sensitive account issues require human review.
- If important information is missing, say so.

Require Specific Output Format: ON

PART 4 — TEST CASES
============================================================

TEST 1 — Technical Support

I completed my course but I cannot download my certificate. Please help me.
Expected: Technical Support, High, knowledge-based response.

TEST 2 — Billing
Subject: Payment deducted but not updated
Body:
I made a payment but the payment status has not been updated. Transaction reference is TXN12345.
Expected: Billing, human review recommended.

TEST 3 — Missing Information
Subject: Something is wrong
Body:
My account has a problem. Please fix it.
Expected: Do not invent the issue; request information or human review.

TEST 4 — Certificate Not Ready
Subject: Where is my certificate?
Body:
I completed my course. When can I download my certificate?
Expected: Use the knowledge-base policy; do not promise an unsupported date.
